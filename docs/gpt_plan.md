# GPT-часть — план карьерного ИИ-консультанта

> Сохранённый дизайн. Реализуем, когда будет ключ OpenAI (~10-е число).
> До этого можно заложить фундамент без API.

## Идея
Персональный карьерный консультант на GPT (`gpt-4o-mini` — дёшево). Ключевая мысль:
**«адаптивность под студента» = его данные в промпте**, а не сложный фреймворк-агент.
В запрос к GPT кладём резюме/навыки студента + его топ-вакансии из семантического
матчинга (`find_matches`). Так GPT отвечает персонально и по делу.

Это соединяет обе половины темы диплома: **анализ навыков ↔ подбор вакансий**.

## Фаза A — разовый анализ (MVP, делаем первым)
Эндпоинт, напр. `GET /me/analysis`:
1. собрать данные студента: `skills` / `resume_text` + топ-N вакансий (из `find_matches`);
2. собрать промпт: «вот резюме и подходящие вакансии — найди пробелы в навыках и составь план обучения»;
3. вызвать GPT;
4. вернуть структурированный ответ (Pydantic): список пробелов + шаги плана обучения.

## Фаза B — чат-консультант (обёртка над A, потом)
Как Kaspi Kasper: студент пишет вопрос → GPT отвечает, видя контекст студента +
историю диалога. Переиспользует сбор данных из A. Эндпоинт, напр. `POST /me/chat`.
A и B — одна система, которая растёт, а не два отдельных проекта.

## Что можно заложить БЕЗ денег на API (фундамент)
- Pydantic-схемы ответа (напр. `SkillGap`, `LearningStep`, `AnalysisOut`);
- скелет эндпоинта: сбор данных студента + **заглушка** вместо GPT-вызова;
- черновик промпта.
На 10-е останется только вставить реальный вызов `openai`.

## Технические заметки
- библиотека `openai`, модель `gpt-4o-mini`;
- ключ `OPENAI_API_KEY` → в `.env`, читать через `app/core/config.py` (settings);
- формат ответа: строгий JSON (надёжнее для интерфейса);
- язык ответов — русский.
